# Predictive Maintenance Intelligence

A machine learning project that analyses machine sensor data to predict machine failure risk. The project will also integrate Generative AI to explain predictions and provide helpful maintenance insights.

## Project Objectives

- Analyse machine sensor and operational data.
- Build a machine learning model to predict machine failures.
- Display predicted failure risk through a dashboard.
- Use Generative AI to explain model predictions and suggest maintenance checks.

## Technology Stack

- **Programming:** Python
- **Data Analysis:** Pandas, NumPy, Matplotlib
- **Machine Learning:** Scikit-learn (planned)
- **Backend:** Node.js and Express.js (planned)
- **Database:** MongoDB (planned)
- **Frontend:** React (planned)
- **Generative AI:** LLM API (planned)

## Dataset

This project uses the AI4I 2020 Predictive Maintenance Dataset from the UCI Machine Learning Repository.

- **Source:** https://archive.ics.uci.edu/dataset/601/ai4i
- **License:** Creative Commons Attribution 4.0 International (CC BY 4.0)
- **DOI:** https://doi.org/10.24432/C5HS5C

The dataset is synthetic and is being used for educational and machine learning experimentation.
